Information about data sources and methodology

📊 COVID-19 Global Dashboard

This dashboard provides a comprehensive visualization of COVID-19 impact data across 25 countries worldwide. It includes interactive charts, maps, and filters to explore pandemic statistics.

Data Sources

  • Our World in Data — COVID-19 dataset
  • Johns Hopkins University — CSSE COVID-19 Data

Features

  • Interactive world map with case distribution
  • Multi-dimensional filtering (continent, country, population, vaccination)
  • Comparative charts across countries and continents
  • Country-level summary with key metrics
  • Vaccination progress tracking

Technology

  • Chart.js for interactive charts
  • Leaflet.js for map visualization
  • PapaParse for CSV data processing
  • Vanilla CSS with custom design system
